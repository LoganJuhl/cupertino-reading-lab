## Project summary

Cupertino Reading Lab v4 is a Cupertino-derived Obsidian theme focused on long-form reading and document consumption. It retains much of Cupertino's interface while adapting document typography, measure, spacing and supporting content. Version 0.4.5 is a review candidate, not a Community-directory release.

## Why I built it

I wanted a document surface that stays comfortable through a long article, lesson or reference note. The work concentrates on sustained reading rather than replacing Cupertino's general interface and navigation design.

## Relationship to Cupertino

This theme is based on the outstanding Cupertino theme created by Alexis C. Cupertino provides much of the visual foundation and native-feeling interface that made this project possible. This project extends that foundation with a different focus: long-form reading and document consumption in Obsidian.

## Major differences

- Centered `36.5rem` prose measure and `1em` rendered paragraph rhythm, retaining Cupertino's 1.6 leading.
- Eight bundled static Newsreader faces; explicit user font selection remains effective.
- Six-level heading hierarchy with authored case and rendered paragraph/section spacing.
- Warm light paper and dark document surfaces with underlined links.
- Restrained callouts with readable titles and retained folding controls.
- Compact tables with native local scrolling and a modest phone width extension.
- Phone text-size floor and wrapping settings rows for the longer theme name.
- Local Mermaid/display-math scrolling and explicit wide-helper measurement corrections.

The [comparison](FEATURE-COMPARISON.md) distinguishes these changes from inherited mobile navigation, focus options, sidebars, cards and helper conventions. There is no claim of a newly invented sticky interface.
